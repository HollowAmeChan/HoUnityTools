# 预置控制器（Controllers）

这里放**我们做好的控制器**（`*.controller`），当成一个仓库用。

## 怎么用

1. 在 Unity 里打开 `HoUnityTools / 面捕 / 控制器编辑`，点「打开目录」——就是打开这个文件夹。
2. 把你要的那份 `.controller` **复制到你的工程里**（`Assets/` 下面随便放哪），
   之后它归你管：改名、移动、在 Animator 窗口里加层改动画，都随你。
3. 回到「控制器编辑」页，把复制出来的那份拖进「控制器」栏，点「原地装配」：
   按槽位名把「动画文件夹」里的片段填进去，再把形态键曲线的路径重绑到「调试对象」的网格上。

工具**不会**替你新建资产：装配是**就地**改你那一份，GUID 不变，已经指向它的引用不会断。

## 为什么放包里

包是 `file:` 引用的，这个文件夹就是磁盘上的普通文件夹。放在这里的好处是：
控制器跟着包一起走版本（我们改一次，所有工程下次打开就拿到新的），
而**你在工程里复制出来的那一份不会被我们动**。

## 现在有什么

还没有。第一份控制器（中间层参数 → 混合树 → 形态键）做完之后放进来。
在此之前，「控制器编辑」页可以做「只重绑网格」：拿任意一份现成控制器，
把它的形态键曲线重绑到你当前的调试对象上。
