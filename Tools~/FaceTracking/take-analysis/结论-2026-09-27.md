## 3. 判别得最好的是 **鼻子那一路**（这台设备上，挤眼=皱鼻）

逐行"单靠它能不能分开"的表里，只有这几根不重叠：

（`mouthPress` 不行：B 组压唇 0.32..0.49 与挤眼的 0.4557.. 重叠 ⇒ **不能拿压唇当门**，否则把 B 组判掉。）

## 4. 推荐式（缝 +0.9634，实测包络内非目标全 0）

```text
读数 = mouthPucker
         * clamp((mouthPucker - 0.41) / 0.02, 0, 1)                              ← 死区：静息天花板 0.3797 + 0.03
         * (1 - clamp((max(noseSneerLeft, noseSneerRight) - 0.54) / 0.05, 0, 1)) ← 鼻门：空带 [0.2942, 0.7821] 的中点
维持 trigger 0.80 / target 1 / threshold 0.05 / hold 0.1   ← 0.80 在空带 [0, 0.9634] 里偏上：
                                                             既兜住"没量到的、不皱鼻的挤眼"（pucker 0.78 也不亮），
                                                             又比最弱那次真噘嘴（0.9634）低 0.16
平滑 0.2
```

同一批数据下的备选（都合格，按"最简"排序）：
* `最简_鼻门 = mouthPucker * (1 - clamp((maxNose - 0.54)/0.05))`：缝 +0.5837（静置 0.3797 直接进读数，要靠触发线挡）
* `减鼻 = mouthPucker - maxNose`：缝 +0.5687（减法版，读数会出负值）
* `裸读数`：缝 +0.1865（不推荐，旧 0.8 就是这一版）

## 5. 还没解决的

* ⚠️ **B 组标签待确认**：若 B 不是噘嘴（例如抿嘴/苦嘴），目标集只剩 A ⇒ 特征可以更简单（甚至裸读数 + 0.8），
  但也意味着要另找"拒绝 B"的手段（B 的 pucker 0.96 骗得过任何触发线 ⇒ 只能靠 press/shrug 反相门）。
* **没量到的邻居**：笑以外还该有 鼓嘴（`cheekPuff` 真动作）、咧嘴/抿嘴、以及"眯眼但不皱鼻"的挤眼。
  鼻门目前只被一个"用力型挤眼"（鼻 0.78..0.90）验证过。
