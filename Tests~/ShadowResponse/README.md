Persistent shadow response authoring checks.

`HoShadowResponseAsset` owns four editable curves and a persistent linear `RGBAHalf` texture subasset. `HoShadowResponseBaker` rebuilds that same texture after explicit edits and Undo, retaining its GUID and local ID. `HoShadowResponseAssetEditor` and the optional LWGUI provider remain part of the package because existing Effect materials reference these authored assets. Materials store texture references rather than references to an Editor class.

The optional LWGUI provider edits the resident owner, supports Save/Discard and deep copies authored curves, and preserves empty curves and wrap modes. The generic catalog discovers one-dimensional native textures beneath Texture2D, ScriptableObject or Material owners within the requested library roots. It excludes two-dimensional skin palettes and does not rewrite curves or texture importers when opening the selector.

Copy `HoShadowResponseLwguiProviderChecks.cs` and `CommercialSkinPaletteChecks.cs` into a disposable private host's `Assets/Editor`. Install the current HoTools shadow response core/provider, local LWGUI 1.41.1+ and Commercial Skin package. Set fresh external `HO_SHADOW_PROVIDER_REPORT` and `HO_COMMERCIAL_PALETTE_REPORT` paths, then run each class's `Run` method with Unity CLI pinned to that host. Both fixtures reject projects outside `D:/Temp` and clean only their own generated test folders.

The provider fixture checks automatic registration, external-owner and material-child catalog discovery, two-dimensional palette exclusion, bounded and empty roots, unchanged passive asset/meta/pixel bytes, curve copying, wrapping, empty curves, stable texture identity, Undo/Redo, Save/Discard and reimport. The Commercial palette fixture checks all nine presets, custom/None, one-step mixed-selection Undo, stale callbacks, resident curve ownership and unchanged palette PNG/meta/userData bytes.

Keep existing authored curve assets, their texture subassets, meta files and adjacent `.asset.recipe.json` provenance together with their actor resources. The external source backups and completed transaction journals remain external evidence. Historical material converters, package cutovers, recovery Apply/Restore entry points and their one-use preparation/verification fixtures are no longer shipped; they can be inspected in Git history without being loaded into the package.
