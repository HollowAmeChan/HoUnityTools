# 摆锤约束设计与验证

## 适用范围

摆锤约束（`HoUnityTools/Constraints/Ho Pendulum Constraint`）把锚点的运动解算成一组摆锤参数，再通过绑定写到材质属性、Shader 全局、UnityEvent 或另一个 Transform。

它解决的问题和旧 `Wobble.cs` 一样：给液面 shader 提供摆动参数。区别在于它是通用组件，输出不再写死成两个材质 float。

它**不写自身 Transform**，定位是参数生成器。要驱动物体就加一条 `Transform` 绑定指向子物体；绑定指向驱动源自身时会被跳过并给出警告，避免自反馈。

当前只实现**弹簧摆**模型（倾斜自由度 + 竖直方向的径向弹簧）。绳索链（多段绳子摆动、逐关节输出）是另一套模型，单独规划。

## 与旧 Wobble 脚本的差异

| 项 | 旧 Wobble | 摆锤约束 |
| --- | --- | --- |
| 驱动量 | 线速度 + 角速度（`(lastPos - pos)/dt`，取负） | 锚点**加速度**，由最近若干帧位置的二次最小二乘拟合给出 |
| 帧率 | 振幅增量没乘 `dt`，60fps 输出约为 30fps 的两倍 | 自动分子步（默认 1/240），阶跃响应在 1/15~1/240 完全一致 |
| 加速度估计 | 无（速度驱动） | 二次最小二乘拟合：对匀速与恒加速精确，抗位置抖动能力比逐帧二阶差分高一个数量级 |
| 频率 | `WobbleSpeed` 直接乘绝对时间，改参数会跳相位 | 液面响应频率独立给定（默认 3Hz），相位累加；摆长只影响可视化与离心半径 |
| 总响应延迟 | 约 0.18s 的隐含滞后 | 估计窗口 (N-1)/2 帧 + 平衡角平滑（默认 6 帧 + 20ms，约 60ms） |
| 饱和 | `atan` 一味增长，靠夹取 | 合成幅值夹取 + 可调软饱和；对角晃动不会到 √2 倍上限 |
| 竖直方向 | 只有两轴倾斜，上下颠簸没有输出 | 径向弹簧给出有效重力与伸长量，上下颠簸有明确响应 |
| 重力/朝向 | 无 | 有效重力方向决定平衡面，物体翻转时液面跟着翻转 |
| 双轴相位 | X/Z 共用 `sin(time)`，只沿一条对角线摆 | 双轴各自独立积分，可打圈 |
| 角速度 | 欧拉角直接相减，±180° 处跳变 | 用四元数增量求角速度，另加物理离心项 |
| 材质写入 | MPB + `mat.SetFloat`（污染共享材质资产） | 默认只写 MPB；需要兼容旧行为时勾选「同时写材质资产」 |
| 输出 | 写死 `_WobbleX` / `_WobbleZ` | 18 个通道 × 4 种绑定目标 |
## 模型

平衡面（全部在锚点本地坐标系）：

```text
vertical    = 球面插值(up, localUp, 朝向跟随)        // 完全反向时绕任意垂直轴旋转，不会塌成零向量
centrifugal = ω × (ω × r)                          // r = -up * 摆长
drive       = a * 灵敏度 + 离心影响 * centrifugal
n_raw       = drive + vertical * g                 // 有效重力的反方向，就是液面平衡法线
g_eff       = |n_raw| / g                          // 有效重力倍率
θ_eq        = (atan2(n.x, |n.y|), atan2(n.z, |n.y|)) 按合成幅值软饱和到 最大倾斜角
θ_eq_filter = 一阶低通(θ_eq, 平衡角平滑)             // 直流增益为 1
```

倾斜自由度按阻尼谐振子追赶平衡角：

```text
θ'' = -ω²(θ - θ_eq_filter) - 2ζω θ'      // ω = 2π * 液面响应频率
```

竖直方向是一维弹簧，静止伸长为 ΔL 时刚度由重力标定：

```text
x'' = -ω_r²(x - x_eq) - 2ζ_r ω_r x'
x_eq = ΔL * (g_eff / g - 1)              // 静止 0，过载为正，失重为负
ω_r  = √(g / ΔL)                         // ΔL = 0.02m 时约 3.5Hz
```

半隐式欧拉积分，按 `最大子步` 自动分子步。

几个直接推论（都已作为断言验证）：

- 恒加速度稳态满足 `tan θ = a / g`（柔和度为 0 时严格成立；默认 0.65 且倾角远低于上限时误差 < 0.5°）。
- 匀速平移的加速度为 0，不会产生稳态倾斜。
- 朝向跟随为 1 时液面保持世界水平：物体侧倾 30°，输出倾角就是 30°；完全倒置时平衡角为 0 而不是 180°。
- 朝向跟随为 0 时液面跟随物体自身轴，但仍然响应加速度。
- 摆长 L 对应的无阻尼周期为 `2π√(L/g)`（勾选「摆长决定频率」时使用），与固有频率 `1/f` 一致。
- 纯竖直运动不产生倾斜（物理正确），但会产生有效重力变化与径向伸缩。
- 1Hz 往复运动下的总相位滞后约 **20°**，旧默认参数下约 **164°**（旧默认把 1Hz 的谐振点放在手持运动频段里，液面几乎反相）。

按帧采样会带来约半帧的群延迟，这是任何离线采样的仿真都有的：低帧率下瞬时值会有相位差，但包络与帧率无关（实测 1/480~1/15 包络偏差 0.38%）。

## 面板结构

分区默认全部折叠，展开状态在同一次编辑器会话内保持（脚本重编译不会丢）。折叠时只看四行摘要：

| 分区 | 折叠时的摘要 | 内容 |
| --- | --- | --- |
| 基本 | 驱动源 · 频率 · 最大角 | 驱动源、液面响应频率（含「摆长决定频率」）、阻尼比、最大倾斜角、加速度灵敏度 |
| 输出绑定 | N 条绑定 | 绑定列表（每条默认折叠，只有新增的那条自动展开）、是否同时写材质资产 |
| 高级 | 更新时机 · 拉伸 · 估计窗口 | 更新时机、摆长与朝向、饱和柔和度、竖直拉伸、采样、手动输入（仅手动模式显示）、初始变换 |
| 调试 | Gizmo 开 | 显示开关、颜色、绘制尺寸、运行时读数 |

顶部工具栏是「清空」与「水瓶液面」两个预设。日常只需要「基本」和「输出绑定」两栏，其余按需展开。

## 参数

| 参数 | 含义 |
| --- | --- |
| 驱动源 | `自身运动` / `父级运动` / `指定锚点` / `手动输入` |
| 摆长 | 摆锤末端到锚点的静止距离；同时是离心项半径。默认**不**决定晃动频率 |
| 摆长决定频率 | 勾选后改用物理单摆频率 `√(g/L)/2π`，摆长越长晃得越慢 |
| 液面响应频率 | Hz。液面晃动快慢由容器与液体决定；手持运动在 0.5~1.5Hz，建议响应频率放在 2.5Hz 以上避免共振滞后 |
| 阻尼比 | 1 为临界阻尼；液面建议 0.15~0.3 |
| 最大倾斜角 | **合成**倾角上限，对角晃动不会超过它 |
| 饱和柔和度 | 0 为硬夹取，1 为最软。软饱和在线性区几乎不改变响应，只把接近上限的拐角磨圆 |
| 加速度灵敏度 | 1 为物理值 |
| 朝向跟随 | 1 表示液面平行于世界水平面，0 表示垂直于物体自身轴 |
| 离心影响 | 旋转离心加速度对液面的影响强度 |
| 参考重力 | 换算平衡角与径向弹簧用的 g |
| 启用竖直拉伸 | 竖直方向是否启用径向弹簧 |
| 静止伸长 | 1g 静止时的伸长量（米），同时决定径向弹簧频率 `√(g/ΔL)/2π`。0 表示刚性 |
| 径向阻尼比 | 竖直伸缩的阻尼比 |
| 速度平滑 | 毫秒。对差分速度做一阶低通，抑制鼠标拖拽与动画抖动 |
| 平衡角平滑 | 毫秒。对平衡角做一阶低通，直流增益为 1，不影响稳态倾角 |
| 最大子步 | 单步积分上限，默认 1/240 |
| 估计窗口 | 帧。对最近这么多帧的位置做二次最小二乘拟合求速度与加速度。越大越抗抖动，代价是约 (窗口-1)/2 帧的额外滞后 |
| 手动加速度 / 输入值 / 输入上下限 / 输入加速度 / 输入轴 | 手动输入模式的驱动量；输入值按区间归一化后乘到输入加速度上 |

## 加速度估计

加速度不是逐帧二阶差分算的，而是对最近 N 帧位置做**二次最小二乘拟合**，取二次项系数：

- 对**匀速**精确（二次项为 0）——这是"持续移动不该抽搐"的关键；
- 对**恒加速**精确（位置本身就是二次的）；
- 时间戳用累计 `deltaTime`，因此编辑器里帧间隔不均匀也成立（脚本用固定步长调 `Evaluate(dt)` 时也成立）。

逐帧二阶差分 `a = Δ²p / dt²` 会把位置抖动放大 `1/dt²` 倍。实测（60fps，匀速横向移动）：

| 工况 | 二阶差分 | 二次拟合（窗口 6） | 改善 |
| --- | --- | --- | --- |
| 平滑匀速 | 0.001 m/s² | ~0 | — |
| 量化 1mm，v=0.20m/s | 2.94 m/s² | 0.42 m/s² | 7× |
| 量化 1mm，v=0.05m/s | 2.08 m/s² | 0.66 m/s² | 3.1× |
| 每 3 帧才更新位置（20Hz 采样） | **44.1 m/s²** | 1.58 m/s² | **28×** |
| 帧间隔抖动 ±30% | 4.84 m/s² | 0.31 m/s² | 15.4× |

44 m/s² 折算成倾角噪声是 77°，也就是液面在极限处来回翻；拟合后是 9°，再经过平衡角平滑与 3Hz 振荡器基本看不出抖动。

窗口长度的取舍（60fps，20Hz 台阶 vs 1Hz 正弦跟踪）：

| 窗口 | 台阶噪声 RMS | 1Hz 幅值误差 | 1Hz 相位滞后 |
| --- | --- | --- | --- |
| 3 | 44.1 m/s² | -0.1% | 6° |
| 5 | 6.3 m/s² | -0.4% | 12° |
| **6（默认）** | **1.58 m/s²** | -0.6% | 15° |
| 9 | 0.29 m/s² | -1.5% | 24° |
| 12 | 0.09 m/s² | -2.7% | 33° |

## 输出通道

| 通道 | 内容 |
| --- | --- |
| 液面倾斜 X / Z | `tan θ`，可直接喂给液面 shader 的 `_LiquidTiltX` / `_LiquidTiltZ` |
| 斜率向量 | `(TiltX, 0, TiltZ)` |
| 倾角 X / Z / 合倾角 | 度。合倾角是幅值，受最大倾斜角限制 |
| 旋转欧拉角 | `(AngleZ, 0, -AngleX)`，把局部 up 转到液面法线，适合让物体随液面倾斜 |
| 摆向 | 摆锤末端相对锚点的世界方向（单位向量） |
| 末端偏移 / 末端位置 | 摆锤末端相对锚点的本地偏移 / 世界坐标，**已含径向伸长** |
| 振幅 | 相对平衡位置的振荡幅度 0~1 |
| 相位 | 累加相位 0~2π |
| 归一化读数 | 手动输入模式为输入值映射，其余模式为倾角 X 相对最大角的映射 |
| 有效重力 | `g_eff / g`：静止 1，自由落体趋近 0，过载大于 1 |
| 伸长量 | 径向弹簧偏移（米）：静止 0，过载为正，失重为负 |
| 锚点速度 / 角速度 / 加速度 | 诊断用 |

## 输出绑定

一条绑定 = 通道 + 缩放 + 偏置 + 目标。标量通道只用 x 分量。

| 目标 | 写入方式 |
| --- | --- |
| 渲染器属性 | 通过 `MaterialPropertyBlock` 写到指定渲染器；渲染器列表为空时按「包含子物体」自动收集 |
| Shader 全局 | `Shader.SetGlobalFloat` |
| UnityEvent | 向量通道走 `UnityEvent<Vector3>`，标量通道走 `UnityEvent<float>` |
| Transform | 按权重驱动目标 Transform 的本地旋转（欧拉角）或本地位置 |

渲染器写入的两个细节：

- 默认**不写材质资产**。旧 Wobble 的 `mat.SetFloat` 会污染共享材质、破坏合批，Warudo 打包后还会影响所有使用同一材质的人。需要兼容旧行为时勾选「同时写材质资产」。
- 同一帧内同一个渲染器只 `GetPropertyBlock` 一次，多条绑定写在同一个属性块上再 `SetPropertyBlock`，因此 `_LiquidTiltX` 与 `_LiquidTiltZ` 不会互相覆盖，同时也不会抹掉其他组件写入的属性。

## 调试视图

Scene 视图里会画出：

- 锚点球、摆线、摆锤球（摆锤位置用真实摆长，这是会输出到 `BobPosition` 的位置）；
- **当前液面**圆盘与法线；
- **平衡液面**圆盘与法线（振荡器正在追赶的目标）——和当前液面对照就能直接看出滞后与振铃；
- **加速度箭头**：驱动整个系统的锚点加速度。1g 的箭头长度由「箭头 1g 长度」参数决定，箭身上画一道 **1g 刻度**，按刻度数就能读出几倍重力；长度超过「箭头最大长度」（默认 2 倍参考尺寸）后不再增长。
- 可选的运动轨迹。

### 绘制尺寸

所有尺寸都从**参考尺寸**派生，与摆长无关（摆长是可视化/离心参数，把它当 Gizmo 基准会导致改摆长时整套绘制跟着塌掉）：

| 元素 | 尺寸 |
| --- | --- |
| 锚点球半径 | 参考尺寸 × 5% |
| 摆锤球半径 | 参考尺寸 × 4.5% |
| 液面盘半径 | 参考尺寸 × 40% |
| 法线长度 | 参考尺寸 × 50% |

参考尺寸有两种来源：

- **尺寸按物体包围盒**（默认）：取驱动源（含子物体）渲染器包围盒的最长边。物体缩放多大都不会看不见。
  渲染器还没有网格、包围盒退化时会回退到手动尺寸，不会塌成 0。
- **手动**：直接给参考尺寸（米）。

两种模式都可以再乘一个「整体缩放」。

## 水瓶液面预设

编辑器工具栏的「水瓶液面」按钮会清空绑定并建立两条渲染器属性绑定：

| 通道 | 属性 | 缩放 |
| --- | --- | --- |
| 液面斜率 X | `_LiquidTiltX` | 2.4 |
| 液面斜率 Z | `_LiquidTiltZ` | 2.4 |

缩放 1 表示通道值就是液面真实斜率 `tan θ`。2.4 是按 60fps 下旧 Wobble 脚本在代表手持运动上的 RMS 标定出来的：

| 帧率 | 旧 Wobble RMS | 旧 Wobble 峰值 | 摆锤 `tanθ` RMS | 比值 |
| --- | --- | --- | --- | --- |
| 60fps | 0.16073 | 0.44995 | 0.06631 | 2.42 |
| 30fps | 0.07804 | 0.22620 | 0.06630 | 1.18 |

旧脚本的比值随帧率变化（因为振幅增量没有乘 `dt`），摆锤约束的比值恒为 1。**新写的液面 shader 如果把 `_LiquidTiltX` / `_LiquidTiltZ` 直接当斜率用，把两条绑定的缩放改成 1**；2.4 只在 shader 侧沿用旧 shader 那套量纲时才有意义。

## 接入 shader

约束输出的是「液面在世界里应该怎么倾斜」，所以 shader 侧最省事的接法是**在世界空间构造液面平面**，而不是像旧 shader 那样拿物体空间的顶点分量去凑：

```hlsl
// _LiquidTiltX / _LiquidTiltZ = 沿世界 X / 世界 Z 的斜率 tanθ，直接来自 TiltX / TiltZ 通道
// _LiquidHeightOffset = 液面相对高度偏移，单位是世界单位（米），可接「伸长量」通道
float3 worldOffset = WorldPosition - objectOriginWorld;
float surfaceHeight = worldOffset.y
                    + _LiquidTiltX * worldOffset.x
                    + _LiquidTiltZ * worldOffset.z
                    + _LiquidHeightOffset;
float clipValue = fillRemap + surfaceHeight / objectScale.y + waveTerm;
clip(clipValue - 0.5);
```

三个要点：

1. **高度项要除以物体缩放**（世界米 → 物体空间单位，和原来一致），但**倾斜项不要重复除**：倾斜项本来就乘在世界偏移上，再除一次缩放会让摆动强度小两个数量级——旧 shader 的 `_WobbleX` / `_WobbleZ` 就是因为这个在 98 倍缩放的液面物体上基本失效。
2. **两个倾斜轴都要取水平方向**：旧 shader 里 `RotateAroundAxis(v, (-1,0,0), 90°)` 得到 `(v.x, v.z, -v.y)`，y 槽落到了高度分量上，所以 `_WobbleZ` 只能整体升降液面、做不出第二个倾斜方向。按上面的世界空间写法就不存在这个问题。
3. **高度偏移用世界单位（米）**，这样可以直接接「伸长量」通道，缩放填 1。

> 旧 shader 的改动已经回退，这里只是接法规格：新 shader 按上面写，两条绑定的属性名用 `_LiquidTiltX` / `_LiquidTiltZ` 即可。

## 水瓶液面预设的其余参数

| 参数 | 值 | 理由 |
| --- | --- | --- |
| 液面响应频率 | 3Hz | 高于手持运动频段（0.5~1.5Hz），避免手抖落在谐振点被 Q=1/(2ζ)≈2.3 放大成来回翻 |
| 阻尼比 | 0.22 | 晃一下就停，但不至于黏住 |
| 最大倾斜角 | 20° | 合成倾角上限，对角晃动也不会超过 |
| 饱和柔和度 | 0.65 | 接近上限时圆滑压缩，不像撞墙 |
| 加速度灵敏度 | **0.5** | 见下 |
| 摆长 | 0.25m | 只影响可视化与离心半径 |
| 静止伸长 | 0.015m | 径向弹簧，约 4Hz |
| 估计窗口 / 平衡角平滑 | 6 帧 / 20ms | 抗抖动与响应速度的平衡点 |

**关于加速度灵敏度 0.5**：灵敏度 1 是物理值（`tanθ = a/g`），但 `a` 只要 **3.6 m/s²** 就会顶到 20° 上限，而场景里拖动物体很容易超过，结果是碟子长期贴在极限处翻动，看起来像抽搐。0.5 把常见手持运动放到量程中段：

| 锚点加速度 | 灵敏度 1 | 灵敏度 0.5（预设） |
| --- | --- | --- |
| 1 m/s² | 5.8° | 2.9° |
| 3 m/s² | 17.0° | 8.7° |
| 7 m/s² | 35.5° → 压缩到约 19° | 19.8° → 压缩到约 17° |
| 15 m/s² | 56.8° → 压缩到约 19° | 37.4° → 压缩到约 19° |

判断当前设置是否合适，直接看调试视图里的**红色加速度箭头**：匀速移动时箭头应该几乎为零（只有启停瞬间有值）；如果箭头一直在乱抖，那是位置抖动，调大「估计窗口」；如果箭头稳定而碟子贴在极限处来回翻，那是灵敏度/上限的问题，调小灵敏度或调大最大倾斜角。

> 注意：摆动属性最终能不能推动液面，取决于 shader 怎么使用它们。`41水瓶` 的 `Liquid.shader` 把摆动项和世界偏移一起除以了物体缩放，在 98 倍缩放的液面物体上这两个属性会被额外缩小两个数量级，需要配合 shader 侧的调整才能看到倾斜。

## 验证

数值验证（dotnet 直接引用 `UnityEngine.CoreModule.dll` 跑纯数学求解器，51 项）：

- 恒加速度稳态 `tanθ = a/g`，a 取 0.5~9.81 与负值，误差 < 0.05°（柔和度 0）。
- 默认参数（柔和度 0.65 + 35ms 平衡角滤波 + 径向弹簧）下中小角度误差 0.31°。
- 静止不产生倾斜；扰动后收敛回水平；小角度自由振荡周期 = `1/f`，误差 0%。
- 阶跃响应在 1/15~1/240 帧率下偏差 0°；正弦驱动包络在 1/480~1/15 下偏差 0.38%。
- `dt = 0` 不改变状态、不产生 NaN；NaN / Infinity 输入被过滤。
- 侧倾 30° 液面保持水平；完全倒置平衡角为 0；朝向跟随为 0 时回到物体自身轴。
- 软饱和：线性区不改变响应，接近上限时明显压缩，渐近线严格不越过最大角；柔和度为 0 时退化为硬夹取。
- 对角晃动按幅值夹取（10° 上限给出 10°，旧实现会到 14.14°）。
- 径向弹簧：静止有效重力 1、不伸长；向上加速 1g 时 `g_eff = 2`、伸长量翻倍；自由落体时 `g_eff → 0`、径向收缩；纯竖直运动不产生倾斜但有伸长；频率 = `√(g/ΔL)/2π`。
- 摆长 0.15~2.5m 的周期与 `2π√(L/g)` 一致，积分实测周期误差 < 0.5%。
- 1Hz 驱动的总相位滞后 20.09°（旧默认 163.89°）。
- 运动估计器：平滑匀速估计加速度 6e-5 m/s²（应为 0）、平滑恒加速精确、20Hz 采样台阶下噪声 1.58 vs 二阶差分 44.1 m/s²（28×）、帧间隔抖动 ±30% 时仍准确、样本不足时输出 0 而不是 NaN。

编辑器集成验证（`-batchmode -executeMethod`，31 项，Unity 2021.3.45f2 与 2022.3.22f1 均通过）：

- 组件与绑定的序列化字段齐全、`AddComponentMenu` 路径正确。
- 匀速无稳态倾斜、恒加速度满足 `tanθ = a/g`、`TiltX = tan(AngleX)`。
- 渲染器属性绑定写入 MPB、值随运动变化、同一渲染器上两条绑定互不覆盖。
- Shader 全局、UnityEvent、Transform 三种绑定实际生效。
- 水瓶预设使用的绑定接口与清空接口。
- 手动输入驱动与归一化读数。
- 静止/过载/纯竖直三种工况下的有效重力与伸长量，摆锤距离随伸长变化。
- 软饱和不越过上限且不会长时间停留在夹取状态。
- 调试绘制参考尺寸：手动值 × 整体缩放且不受摆长影响（摆长 0 也成立）、渲染器没有网格时回退而不是塌成 0、自动模式取包围盒最长边、自动模式下整体缩放仍生效。

## 后续规划：绳索链

弹簧摆用单个等效摆描述液面，加上一维径向弹簧表达竖直伸缩；它没有多段绳子的弯曲与甩动。绳索链需要另一套求解器（Verlet 质点链 + 距离约束 + 逐关节输出），目前不在本组件内，按独立组件规划。
