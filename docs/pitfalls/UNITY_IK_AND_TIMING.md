# Animator IK 与更新时机

## 1. 头一动不动？先看这三条

| 症状 | 原因 | 怎么办 |
| --- | --- | --- |
| 头完全不动，眼睛形态键正常 | 动画图层没勾 **IK Pass** → `OnAnimatorIK` **根本不会被调用**。这是"头一动不动"最常见的原因 | Animator 窗口 → Layers → 图层行右侧齿轮 ⚙ → IK Pass（Unity 6 里选中图层后 Inspector 也显示这个勾）。**每个想参与 IK 的图层都要勾** |
| 组件在子物体上，IK 收不到 | Unity 只把 `OnAnimatorIK` 发给**Animator 所在的那个 GameObject**（和 `OnAnimatorMove` 一样） | 组件与 Animator 不同物体时，播放时会自动往 Animator 物体挂 `HoLookAtIkRelay` 转发（编辑模式不加组件，避免标脏场景） |
| 编辑器里正常，离屏测试头不动 | `Animator.Culling Mode` 是 `Cull Update Transforms` / `Cull Completely` | 离屏不更新是**正常的**；测的时候换 `AlwaysAnimate` |
| 模型没有 Avatar / 不是 human | 头部整块不生效（面板会报错） | 眼睛形态键部分照常，头需要 humanoid |

## 2. 头骨骼的"绝对朝向"在它自己的局部坐标系里算不出来

症状：头和眼睛**固定偏几度**（换个模型偏的量还不一样）。
原因：局部坐标系里差的正好是"静止姿势本身那一份头部角度"（对模型是常数）。拿"IK 前→后的旋转增量"当绝对朝向，
等于把这份常数丢掉。

怎么办：**绝对朝向按 Unity 的瞄准契约估计**（我们让它看哪、它就朝哪，再乘 `totalWeight × headWeight`）；
旋转增量只当调试信息；模型自身的固定偏差用「头朝向偏差」trim 补（正常模型填 0）。
眼睛残余 = `目标 − 头部估计`，所以 `headWeight` 调多少都不影响落点，「只看眼睛」时也不会只补三成。

## 3. 下游读到的总是上一帧

症状：尾巴 / 布料"**一阵一阵**"抽搐（跟随约束在 `LateUpdate` 写，消费它的 IK 也在 `LateUpdate` 读）。
原因：同为 `LateUpdate` 时，下游这一帧只能读到上一帧的值。

怎么办：**会被同一帧下游消费的跟随物用 `Update`，并显式钉住顺序** ——
Project Settings → Script Execution Order 加 `HoFollowConstraint`，顺序 `-100`（`RigBuilder` 默认 0，一定排在我们后面）。

⚠️ 只改成 `Update` 通常就够了，但那是"**碰巧排在前**"：Unity 不保证同为默认顺序的脚本谁先谁后
（官方文档明说不能依赖同一事件函数在不同 GameObject 之间的调用顺序）。换机器、加脚本、升级版本都可能翻掉，
而翻掉的表现又正好是同一句"一阵一阵"。

- 不要为了更早插到 `Update` 之前（那会早于动画写姿势，读到更旧的输入）。
- 不要用 `FixedUpdate` 顶替（与渲染帧不同步）。
- 不要去提前 MagicaCloth2（它读骨头、不读跟随物）。

## 4. 同一根骨头只留一个"会动"的写者

症状：`ChainIKConstraint` 与 BoneCloth 覆盖同一条骨链时，**谁后写谁赢，参数怎么调都只是压制**。
怎么办：二选一 —— 主干给确定性的 IK，布料只做叶子。另外顺手检查 MC2 的参数：

- `移动速度制限 / 本地移动速度制限` 出厂是世界 5 m/s、本地关闭；被填成 1 m/s 且勾选时，
  基准姿势速度在阈值上下浮动会被反复"**拽住 / 松开**"。
- `相机剔除 = AnimatorLinkage` 会在角色被剔除时重置或暂停模拟。

## 5. 甩飞不是滞后：`maxVelocity` 夹的是修正速度

症状：父级速度一旦超过上限，跟点**永远追不上**，偏移无界增长（实测父级 10 m/s、上限 1 → 偏 27 m）。
原因：旧版夹的是**世界速度**。夹取搬进坐标系之后才回到本意：限制软跟随的**修正**速度。

## 6. 眨眼加速度：量纲与冲量宽度

- **量纲**：`a = 曲线''(t) / 闭合时长²`。默认曲线在闭合起点的 `|y''| ≈ 4.9`，闭合 80 ms 时真实量级 **~760 /s²**，
  随时长与曲线形状漂移 → 按**曲线自身的最大 |y''|**（构建期采 64 点量一次）归一化，峰值才稳定在 1 附近。
- **冲量太窄**：尖峰只有闭合时长的 **~10%**（80 ms → 约 8 ms）。二阶系统对冲量的峰值响应 ≈ `ω·I`，
  **9 Hz 弹簧对 8 ms 冲量只有 ~0.5 的响应**，且随频率剧烈变化 → 每条规则再把它摊成「瞬间起峰 + 按包络衰减」的小鼓包。

## 7. 眼球骨骼 pivot 不在眼球中心

症状：眼球转起来像"翻白眼"。
原因：我们走世界叠加旋转、轴向不影响，但**pivot 偏了就会绕错点转**。
