# Ho PMX 场景导入

直接把 .pmx 和引用的贴图放入 Unity 项目。PMX 会成为可拖入场景的模型资产，初始材质使用 Ho 渲专用 lilToon。此功能面向单向使用的静态场景资产。

## 放置文件

保留源包的相对目录，例如：

~~~text
Assets/Stages/云景千山/
  云景千山v2.pmx
  textures/
  Ray_FX_20260524_084044/
    Material_MME.emd
    *.fx
    *.fxsub
~~~

PMX 贴图路径以 PMX 所在目录为基准；EMD 引用以 EMD 所在目录为基准；Ray 图片路径以对应 FX 所在目录为基准。支持正斜杠、反斜杠和 ../，不按全工程同名图片猜配。

图片应位于 Unity 的 Assets 或 Packages 内。E 盘的素材目录是源库，需要先把要使用的源包及有效依赖复制到项目。

## Inspector

选中 PMX 后有三个页签，修改后使用原生 Apply / Revert：

| 页签 | 设置 |
| --- | --- |
| 模型 | 缩放、重算法线、启用源描边 |
| 材质 | 读取 Ray 配套材质、可选 EMD、逐材质透明覆盖、外部材质关联、提取材质 |
| 表情 | 选择导入时烘焙的顶点、UV、材质或 Group 表情权重 |

默认缩放为 0.08，保留原始法线。坐标为 Y 轴旋转 180 度，保留三角索引顺序；主 UV 的 V 翻转一次。每个非空源材质生成一个静态 MeshRenderer，保留对应双面和投影/接影标志。

透明自动分类结合材质 Alpha 与该材质的 UV 覆盖区域：连续半透明进入 Transparent，有孔洞/少量抗锯齿边缘进入 Cutout，完全不透明进入 Opaque。分类是有界分辨率的启发式；图集细小区域、平铺和特殊透明 pass 可在材质页覆盖。已识别的 Ray 专用 Cutout 使用源设置的阈值。

裁切仍由材质的 _Cutoff 参数控制：Transparent 的初始值为 0.001，Cutout 默认 0.5 或采用 Ray 专用阈值。提取材质后可在 lilToon Inspector 自行调整；没有修改 shader 的裁切实现。

## 提取材质

1. 应用初始导入设置。
2. 在材质页点击“提取材质…”并选择 Assets 内的文件夹。
3. 生成的 .mat 自动关联回 PMX，后续直接编辑这些材质。

提取不会覆盖现有同名文件，会生成唯一文件名。原有 PNG/TGA 等图片仍是外部引用。为线性采样或通道转换生成的法线/金属/光滑度贴图会一并复制为 Textures/*.asset，保证提取后的材质可以独立调整。

重导入或调整模型缩放继续引用已提取材质，不把材质重置为生成值。此时修改材质参数、透明方式和描边请直接编辑外部 .mat；导入器的初始生成规则不会覆盖它。需要重新生成某个材质时，清空该槽“外部材质”关联，再提取新版本。

## Ray 支持范围

开启“读取 Ray 配套材质”后，自动查找 PMX 同目录及直属子目录中的唯一 Material_MME.emd。存在多份时列出提示，由用户在 Inspector 指定文件，不自动挑选。

支持已知 material_common 模板的：

- EMD 中 Obj[材质槽序号] 到 FX 的映射。
- 法线 Type 0/1、强度、UV 翻转和重复；基于 V 已翻转的网格重算切线，普通 Ray 法线不额外翻绿。
- 金属贴图的有效来源、RGBA 单通道与常量乘法/幂运算。
- 光滑度贴图、粗糙度转换、常量和 MaterialPower 转换；高光系数使用 1 - pow(2 / (power + 2), 0.125)。
- 已知专用 Cutout 模板；已启用的基本 Emissive 设置。

默认材质只使用 Ho lilToon。法线、金属、光滑度数据图按线性数据读取，不修改原贴图的 Import Settings；相同转换在一次导入内复用。

仅解析数据与已知宏，不执行 MME 程序。禁用的占位贴图不作为缺失依赖；未知 FX、其他法线类型和未支持的宏会记录提示。

## 表情和限制

表情权重在导入时烘焙，结果是静态网格/材质状态。顶点和 UV 偏移支持烘焙；材质支持 Diffuse、Ambient、Specular、高光、描边数值；Group 展开后作用于这些类型。材质贴图独立乘加系数尚未烘焙，会明确提示。

源 Toon、Sphere、共享 Toon 索引和材质参数保存在导入信息中。初始材质使用 Ho lilToon 阴影参数，没有把 MMD 光照 Ramp 直接当作模型 UV 阴影贴图；Sphere 混合尚未自动实现。

当前不执行骨骼动画/IK/SDEF/物理求解，不重建任意 MME、AutoLuminous、灯光、天空环境或后处理。源骨骼/物理数量可在导入报告查阅。PMX 2.0/2.1 能解析静态几何，2.1 的特殊顶点颜色/点线绘制尚未实现。

实际集成验证环境为 Unity 6000.3.15f1、HoURP 17.3 和本机 Ho lilToon。缺少目标 shader 时导入明确报错。

导入/编辑器流程已通过七份实际 PMX 的 158 项检查。Gamma + D3D11 的四场景基线渲染烟测通过；补充的 Linear 测试遇到 GPU device lost/hung，另一个 Gamma 视角探针也停滞，原因尚未定位。跨颜色空间和视角的图形验收仍未完成，不能据此声称已完成画质验收。完整记录见 [验证结果](../../Tests~/PmxImport/ValidationResults-20261028.json)。

## 实现与验证

实现位于 Editor/PmxImport/，独立 Editor 程序集不依赖 MMD 动画/物理插件。

本机七份验证样本覆盖马戏团、血月古堡、云景千山以及朱木古堂四个组件。复现入口见 [PMX 验证说明](../../Tools~/PmxImport/README.md)，上游参考与取舍见 [导入器调研](../research/PMX_IMPORT_REFERENCES.md)。
