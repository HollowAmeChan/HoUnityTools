# VMD 动作播放与骨骼绑定

组件入口：**Add Component → HoUnityTools → MMD → VMD Motion Player**。导入检查和绑定工具入口统一在 **HoUnityTools → MMD → 角色绑定与表情检查**，或直接选中 `.vmd` 使用中文导入面板。

## WTD 的配置顺序

1. 把动作 `.vmd` 拖入播放器的 **VMD 动画**。镜头 VMD 使用 Camera Player。
2. **角色根** 拖入 `WTD-BUILD`。搜索范围要覆盖主骨架、脸部网格和 `_Constraint` 下的 IK 控制空物体，不能只指定衣服骨架。
3. **生成时使用主骨架** 选择同一个角色实例下的 `Armature-Swimsuit`。`Armature-Miko` 在运行时合并，不用于初始骨骼映射。
4. 点击 **生成并使用角色绑定配置…**，在角色目录保存 `.asset`。按钮会赋给当前播放器；从 VMD 导入面板生成时，需要自行把生成资产拖入播放器的 **角色绑定配置**。
5. 展开 **局部绑定与缺项**。需覆盖配置的轨道在 **骨骼绑定** 中逐项指定；**填充动作骨骼列表（保留已有绑定）** 会补出当前动作的源名称，已有项不覆盖。目标空白是待处理项，不代表动作里没有这条轨道。
6. 点击 **检查角色表情依赖**，处理缺失或冲突。最后进入 Play 模式，使用 **播放 / 暂停 / 从头播放**。帧率默认 30，按动作作者说明设置。

这些生成和检查按钮不会自动完成 FBX 骨轴重定向。首次适配要检查姿势、脚底、膝盖、模型比例和中心轨道，不能仅凭“有映射”判定播放正确。

## Bone Bindings 填什么

每项是 **VMD 源骨骼名 → Unity 目标 Transform**。点 **轨道** 从当前动作的真实源名中选择，再拖入主骨架的对应 Transform。名称不需要相同。

| VMD 源名 | WTD 目标 |
| --- | --- |
| `左足` / `右足` | `Armature-Swimsuit/hips/upper_leg.L` / `.R` |
| `左ひざ` / `右ひざ` | 对应的 `lower_leg.L` / `.R` |
| `左足首` / `右足首` | 对应的 `foot.L` / `.R` |
| `左つま先` / `右つま先` | 对应的 `toes.L` / `.R` |
| `左足ＩＫ` / `右足ＩＫ` | 左右脚 IK 的 **Target 控制空物体** |
| `左つま先ＩＫ` / `右つま先ＩＫ` | 左右 toe IK 的 **Target 控制空物体** |

绑定优先级是组件局部绑定、角色配置、精确同名自动匹配。使用配置后，**Bone Bindings 可以为空**；它用于局部覆盖和补缺，不要求把所有骨骼复制进列表。配置路径以播放器的 **角色根** 为基准，局部绑定则直接引用 Transform。

`センター`、`グルーブ`、`腰`、`下半身` 可能是不同的控制层。不要把这些轨道全部写到 hips，会产生覆盖；当前生成器让无法确定的中心层保持未绑定。WIK/twist、眼睛或手指的专用控制同样需要按角色结构核对。IK 开关使用 Ho IK 的名称或配置映射，控制空物体的运动则通过骨骼轨道绑定。

## 表情检查和灰色预览

旧界面的检查按钮被放进 Unity 的 **Imported Object** 只读预览，所以整体是灰色的。现在统计、角色选择、生成配置与检查按钮位于正式的中文 VMD 导入 Inspector。只有尚未填写目标角色时，相应操作按钮才禁用。

可以直接拖入场景角色或 prefab；无需同时选中 VMD 和角色，也无需锁 Inspector。检查只读角色，JSON 存在 `Library/HoMmdStages/MorphAudit/`，面板也会列出缺失和冲突。规范化命中是名称候选，需要保存到角色配置才会参与播放。

验证入口：`Tests~/MmdMotion/VmdAuthoringValidation.cs`。在安装该包的 Unity 工程内临时复制到 Editor 目录，调用 `VmdAuthoringValidation.Run()`；结果写到 `Library/HoMmdStages/vmd-authoring-validation.json`，临时测试资产自动删除。
