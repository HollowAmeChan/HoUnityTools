# VTS 果冻眼

实现日期：2026-11-03。组件为 `HoVtsJellyEye`，入口是 **Add Component → HoUnityTools → 面捕 → VTS 果冻眼**。

一个组件控制一套瞳孔或高光形态键，内部固定提供位移、缩放、压扁拉长三类效果。瞳孔、高光 1、高光 2 各挂一个组件，可挂在同一物体上，也可作为 HoVTS 下的独立子物体。各实例独立保存弹簧状态与参数。

本组件只消费 IR 最终形态键结果，不读取骨骼、头部姿态、raw 或 value 参数，不修改 Transform。

## 配置

1. 指定角色已有的 **表情 IR**（`HoVtsIrController`）。
2. 填写 **驱动网格** `SkinnedMeshRenderer` 列表。只写列表内网格的同名键，不扫描其他物体；不同网格可以只包含部分目标键。
3. 在 **IR 输入形态键** 配置眨眼／激励键与可选的视线左、右、上、下键。可手动输入名字，也可从 IR 声明的目标中选择。名字指模型最终形态键，不是 value 参数名。
4. 分别填三类效果的输出键。可从驱动网格的形态键列表选择，所有方向都允许留空；至少一个输出键必须存在。
5. 正式运行保持 IR 和果冻组件的 **自动运行** 打开。关闭自动运行只关闭自动推进，供显式调用 `EvaluateNow()` / `Step(deltaTime)` 的宿主调度使用。

源输入键必须是 IR 实际绑定并写出的键。IR 声明了目标但其网格列表里没有该键时，没有可供果冻消费的结果；运行面板会提示“输入键不存在或未绑定”。

### 输入

| 字段 | 行为 |
| --- | --- |
| 眨眼／激励键 | 多个键取最大值，负值不增加激励。可同时填左右眨眼键，单眼变化也会激发效果 |
| 视线左／右 | `右 − 左` 构成水平输入；任意一侧可空 |
| 视线上／下 | `上 − 下` 构成垂直输入；任意一侧可空 |
| 激励水平／垂直影响 | 在位移的弹簧参数中配置，决定眨眼／激励对位移输入的影响；0 表示只使用视线输入 |

缩放与压扁拉长使用眨眼／激励输入，各有自己的弹簧。位移同时使用方向输入和激励，水平、垂直各有一条状态独立的弹簧，两轴共享该类效果的参数。

输入按 Unity 形态键权重 **100 = 1** 换算，已包含 IR 的最终范围限制与 Unity 权重倍率。仅用于数值保护，进入弹簧的归一化输入限制在 ±10。

### 输出

| 效果 | 形态键 | 正负映射 |
| --- | --- | --- |
| 上下左右移动 | 左、右、上、下 | 水平正值写右、负值写左；垂直正值写上、负值写下 |
| 放大缩小 | 放大、缩小 | 正值放大，负值缩小 |
| 压扁拉长 | 压扁、拉长 | 负值压扁，正值拉长 |

激励突然上升时，弹簧先落后于输入，因此先产生负附加量：缩小、压扁，然后向相反方向回弹。若模型键的视觉含义相反，可交换对应的两个输出名称。位移的激励影响也可改正负号。

空方向只跳过写入，不删除弹簧的另一半运动。只有“压扁”而没有“拉长”的模型也能归中。填了名字但全部网格都找不到时会提示；只要其他输出有效，它们继续运行。

## 弹簧参数

每类效果都有独立的强度与弹簧设置：

| 参数 | 范围／默认 | 含义 |
| --- | --- | --- |
| 强度 | 0～2，默认 1 | 在输出端缩放附加量；0 恢复该类输出的中性值，内部状态继续推进 |
| 响应频率 | 0.1～30 Hz，默认 6 | 来回弹动的快慢 |
| 阻尼 | 0.05～2，默认 0.35 | 越低，振铃越明显；1 为临界阻尼。始终保留正阻尼以便归中 |
| 输入平滑 | 0～0.2 秒，默认 0.01 | 抑制输入噪声；过大会削弱瞬间的弹动 |
| 最大附加权重 | 0～100，默认 35 | 限制该类效果正负附加量的峰值 |

位移的默认激励水平影响为 0，垂直影响为 0.35。正的垂直影响在闭眼／激励上升时先向下，随后回弹向上。

调试时可先把瞳孔设得稳一些、力度小一些，再让两层高光使用不同频率。例如瞳孔 8 Hz / 阻尼 0.55，高光 1 为 5 Hz / 0.3，高光 2 为 9 Hz / 0.25；这些只是手感调试起点，不是针对具体模型验收过的预设。

## 归中与写入

附加量使用：

```text
附加量 = 强度 ×（弹簧跟随值 − 平滑后的输入）
```

持续看向一个方向或持续闭眼时，弹簧追上输入，附加量回到零。组件不会把上一帧写出的输出重新累加为下一帧基准。

每个实际输出键接管时单独记录中性权重。每帧从这份中性值加上对应方向的非负附加量；归零也写回中性值。正常 0～100 中性范围内，附加形变不超过该键到 100 的剩余空间。非零中性值会保留，停用时不强制清成 0。

强度与输出幅度限制不反馈进内部状态，空方向、饱和输出也不改变弹簧归中。首次输入、重新连接以及 IR 绑定重建时按当前输入初始化，速度清零。超过 0.25 秒的单步按暂停／跳转处理，直接复位，避免长帧爆冲。

## 调度、丢追与冲突

- 接收器执行顺序为 30000，IR 为 31000，果冻为 31500。三个消费者读同一份已完成结果，不触发 IR 再求值，也不回读自己的输出。
- IR 缓存仅包含实际写到至少一个清单内网格的最终权重。`TryGetFinalWeight()` 和 `CopyFinalWeightsTo()` 均为只读入口；`HasOutputFrame` 拒绝追踪失效、接收器求值已更新但 IR 尚未更新等旧结果。
- 丢追、输入超时或源 IR 停用时，已有运动在最后一个平衡位置衰减，不把“断流”伪造成一记新的反向动作。归中后交还输出键。
- 停用、销毁、替换引用、修改输入／输出名或网格列表时，释放原绑定；网格本体更换后重新按名称绑定。调频率、阻尼、强度等参数不会重建全部弹簧。
- IR 与果冻都登记形态键占用。果冻不能写源 IR 已绑定的同一个网格／键，多个果冻组件也不能重复拥有同一个网格／键。全部键预留成功后才开始写，不留下半套输出。
- 交还时只恢复本组件仍拥有、且仍是其最后写入值的键。外部系统已写入更新值时，不用旧基准覆盖它。

IR 仍是静态表情求值器。果冻的时间状态属于角色组件，不写回两份作品 JSON，也不要求新增作品文件。配置保存在角色 Prefab 中。

```powershell

.\Tests~\VtsComponents\RunJellyEye.ps1 -PlayMode
```

默认在包内忽略目录 `Temp~/VtsJellyValidation` 创建有标记的临时工程；也可显式传入 `-Project` 和 `-Unity`。拒绝往没有验证标记的已有工程安装脚本。
